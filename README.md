# Dynamic CMS Editor AI Agents Skill

Reusable migration and engineering guidance for on-page editing, draft/preview/published modes, versioned releases and rollback, Supabase/PostgreSQL storage, media and icons, dynamic theme controls, animation, and contextual blog/project/footer/updates widgets.

Read SKILL.md first. The complete selected SMTS UAT source reference is organized under reference/ and pinned in reference/SMTS_UAT_MANIFEST.json; current source parity is verified with node scripts/check-source-parity.mjs. The reference includes site-specific examples and is not a turnkey CMS package for every framework. Use WEBSITE_MIGRATION_PLAYBOOK.md to adopt the behavior without replacing another site's design or adding unnecessary editing dialogs.

This skill remains independent from the SMTS deployment. Source synchronization does not install, migrate or deploy the target website.
